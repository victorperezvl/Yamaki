Yamaki - Gestión de Citas para Peluquerías
Aplicación web para la gestión eficiente de citas en una peluquería. Incluye autenticación, control de clientes y sistema de puntos.

Características:
  - Registro e inicio de sesión de clientes y peluqueros.
  - Reservar y cancelar citas.
  - Gestión de clientes por parte de los peluqueros.
  - Sistema de puntos de fidelidad.
  - Notificaciones por email.
  - Seguridad con JWT.

Tecnologías: 
  - Backend: Node.js, Express, MySQL
  - Autenticación: JWT
  - DB: MySQL2
  - Frontend: React
